Usage Guidance

DO/DON'T pairing rule: A DO/DON'T table row always holds a matched pair (a DO and its opposite DON'T describing the same rule from both sides). Never add a row with an empty or placeholder ("—") cell just to keep an unpaired item in the same table. If a DO (or a DON'T) has no genuine opposite in the source, it does NOT belong in this table — pull it out into its own single-column table instead (header colored DO-green or DON'T-red as appropriate, one row per unpaired item; group multiple unpaired items of the same polarity together in that one table rather than one table per item). This keeps every table on the page either a real comparison (2-3 matched columns) or a clearly-labeled standalone callout — never a half-empty row.
