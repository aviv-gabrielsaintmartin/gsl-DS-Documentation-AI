# Line chart

Line charts are effective tools for showcasing trends in numerical data, especially continuous data over time, enabling quick analysis.

| DO |
| --- |
| ![](blob:https://media.staging.atl-paas.net/?type=file&localId=null&id=9f7e287a-ed76-4721-b0d7-f8b7ff4ede71&&collection=contentId-2831286379&height=386&occurrenceKey=null&width=341&__contextId=null&__displayType=null&__external=false&__fileMimeType=null&__fileName=null&__fileSize=null&__mediaTraceId=null&url=null) **DO:** Use a baseline different than 0 accordingly to your data. | CAUTION |
| --- |
| ![](blob:https://media.staging.atl-paas.net/?type=file&localId=null&id=5497a169-91e9-4fc1-a00d-74372d711779&&collection=contentId-2831286379&height=397&occurrenceKey=null&width=341&__contextId=null&__displayType=null&__external=false&__fileMimeType=null&__fileName=null&__fileSize=null&__mediaTraceId=null&url=null) **CAUTION:** Limit the number of lines to 4 or 5 to maintain clarity. Exceeding this limit may result in a confusing "spaghetti chart" with excessive line overlaps. |
| ![](blob:https://media.staging.atl-paas.net/?type=file&localId=null&id=4f86cd4c-7913-4299-958b-3a4bd4199b2a&&collection=contentId-2831286379&height=365&occurrenceKey=null&width=855&__contextId=null&__displayType=null&__external=false&__fileMimeType=null&__fileName=null&__fileSize=null&__mediaTraceId=null&url=null) **CAUTION:** Be careful about the width/height ratio as it can affect how trends are perceived in line charts. A broader chart can create the impression of smoother trends, while a more compact chart emphasizes data fluctuations. It's important to consider how design choices impact the interpretation of the chart. |
