# Radius tokens

Corner radius values. Use for cards, buttons, inputs and any rounded container. Values in px.

| Token | Value | Notes |
| --- | --- | --- |
| `Radius/None` | 0 |  |
| `Radius/4` | 4 |  |
| `Radius/8` | 8 |  |
| `Radius/16` | 16 |  |
| `Radius/Rounded` | 10000 | Fully rounded / pill. A clamp value, not a literal radius. |
