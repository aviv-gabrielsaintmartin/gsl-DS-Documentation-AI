# Missing Images Audit

Images referenced by the Confluence export that don't exist in any local
Zeroheight image export folder (`zeroheight export/08 Images export/`) — most
likely uploaded straight to the Confluence page after the bulk Zeroheight sync.
Each component's `.md` keeps the original Confluence attachment URL for these,
flagged inline with `<!-- MISSING LOCAL IMAGE: <filename> -->`, so they're easy
to find and fix once the real image is available.
