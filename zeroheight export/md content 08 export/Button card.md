## Usage

Button cards are prominent clickable containers. They are mainly used as navigational elements, for example, to navigate from an overview to a detail page.

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/75d12b4cdae8eff7e42109?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T130817Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=32235e418131a0cee64cae358b11d3ee372fbe1a9f87e7e571c7ee9504fb7020)

Do

Use button cards to navigate to other pages.

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/48db452b63938243581bfd?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T130817Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=9e34d6955ef4342b411daf16b248cc6cbfb5e78dca82c9d57d30d86beab3f91d)

Don't use button cards for selection. Use select cards instead.

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/fe75104f617595639a06d9?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T130817Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=482e7cffa588448c2dd1ff63976805b067f023573673e2206724fa6da4597d3f)

Caution

If you need more flexible button cards that include images or descriptions, for example, consider using cell contents and wrapping them in a card.

## Content

Button card labels should be clear and concise. Our users should be able to anticipate where the button card leads to.

Use sentence case without punctuation.

For more information on content guidelines, please refer to the [UX Writing principles](https://zeroheight.com/626199550/v/latest/p/324518-intro).
