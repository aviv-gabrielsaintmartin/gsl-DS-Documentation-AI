A bar chart, or bar graph, shows numeric values as bars, with one axis for categories and the other for values. Each bar represents a category, with length indicating the value.

This chart aids in comparing values easily. It's great for data distribution and metric comparisons, making it easy to spot trends.

Bar charts are widely used for various tasks.

**Arrange the bar order to serve your message**

![](/uploads/Bo3EuMEGLzsjfdB9c9HXxA.jpg)

Do

If your objective is to rank different values, then order them from the greatest value on the left to the lowest value on the right.

  

**Use a 0 value baseline**

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/e3bdbc4ddab303cd19d5a3?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T130716Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=5ca6895d57a338ca333418cb64f4d4c0b5b7b5b6b05540bac0554bdaf77fc56d)

Don’t

A bar chart with a non-zero baseline has the potential to mislead when comparing different groups. The bar lengths on the chart may not accurately reflect the true values they are meant to represent.

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/98be152baef82b53937760?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T130716Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=c39efa0edc2fc596d199de808551ede7b17cba16e6a4aaddcc90db2d56f028da)

Do

The zero baseline not only simplifies the comparison of bar lengths for readers but also ensures the accuracy of your data visualization.

  

**When dealing with lengthy category labels, opt for the horizontal variant**

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/f63aa880b63bc0131d76ca?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T130716Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=390721e40eb1ed99c9b4c0c84247f30a4fc227b5afeab30eb254d455a9137877)

Don’t

Vertical charts may cause label overlap, requiring rotation or shifting for readability, which the horizontal orientation prevent

Use an horizontal layout (bar chart) easing the readibility

  

**When the number of categories is greater than seven, opt for the horizontal variant**

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/bd966f107431fd4f01950f?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T130716Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=979449056a3c85c80be9112acf4c436f463062f108a6be35c8673b67fec9cb5a)

Caution

When working with a vertical layout like a column chart, it is crucial to consider the amount of data displayed, especially on mobile devices. Too much data can hinder users from easily scanning and understanding the information presented.

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/9385e7dd144a4b193ad288?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T130716Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=d0505b0ec1cdc5464716bb4bf0950aa01edc58f9d824431aba078a120ce990b4)

The horizontal layout (bar chart) allows a much better visual organization, an easier readability for the user.

  

**Maintain the rectangular slightly rounded bar shape**

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/97c9f2937b042f934a374a?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T130716Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=e4e9b8a38bb27ccf14953e7b59d2142ff03ab5a3582587adf80cc1839d82c351)

Don’t

Don't change the radius of rounded bar corner

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/0757e30d2d40e5ef52a106?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T130716Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=38eb008a47886bd46e8b405a65bbc60813061f4511d87851aa199b838d73b0f7)

Do

This design allows users to understand the value of each bar easily and simplifies direct comparisons between them. Keep the the slightly rounded corner at 4px

  

**Use one color consistently when competing on the same scale**

![](/uploads/Wj1hkUAEbCI7Pg-iyE0UoQ.jpg)

Don’t

Don't use different bar colors when competing against the same measure (e.g. K/€) Exceptions are only allowed when colors have a specific meaning (e.g. red for Se Loger, blue for Immonet, yellow for Immowelt...)

![](/uploads/-1Okf2N_kkXToCNFYRYMvQ.jpg)

Do

If colors don't aid in understanding the graph or compete with the same value, stick with the default color for each bar.

  

**Highlight data with color**

### Tooltip

When hovering over a bar with the pointer on a desktop or touching it on a mobile, a tooltip will appear, showing the value of the selected item.

Users should be able to control when tooltips disappear, by moving the mouse away or clicking outside the tooltip.

The position is automated.
