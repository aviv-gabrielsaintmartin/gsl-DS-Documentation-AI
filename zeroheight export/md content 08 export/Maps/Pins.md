## Usage

Pins are used to indicate exact or approximate locations of an item users are interested into knowing where the item is placed on a map.

This component is meant to be used only over a map

  

---

  

## Variants

Depending on the type of pin you use you'll be giving different information to the user like if the user has already seen the item, if it is highlighted or even if the location is exact or approximate

**Variant**

**Options**

**Location type**

**State**

**Content type**
