## Usage

The rating is a non-interactive component used to display the results of user ratings and provide a quick overview of user satisfaction.

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/d1670b2dfe3591c7cafb63?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T132922Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=4380b5105e0020dfaa19630fbddb9874cb91481ff3d960a397f85cdd3d5781f7)

![](https://zeroheight-uploads.s3-accelerate.amazonaws.com/bb1b6d2794d3ca4b771aae?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T132922Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=1c3de5e904719cde11ee728747ee2dc08eb7da5556d62812d91f9f4b85e57d37)

## Content

### Rating results

The notation of the rating result depends on the language. For French, German, Spanish, and Dutch content, we write ratings using commas. In English, we write ratings with decimal points.

![ ](https://zeroheight-uploads.s3.eu-west-1.amazonaws.com/c5902d7ebcbef8781f991c?X-Amz-Algorithm=AWS4-HMAC-SHA256&X-Amz-Credential=AKIA3AVNYHQKWXNYIVGF%2F20260901%2Feu-west-1%2Fs3%2Faws4_request&X-Amz-Date=20260901T073752Z&X-Amz-Expires=86400&X-Amz-SignedHeaders=host&X-Amz-Signature=4b33127ba84cbd329696e614d6505293638cc5b990d5abc3e9a4ed9e307ca681)

### Reviews

We use the following abbreviations for numbers.

  

**English:**

-   **K** for thousands
    
-   **M** for millions
    

**French:**

-   **k** for "mille" (thousand)
    
-   **M** for "million" (million)
    

**Dutch:**

-   **K** for "duizend" (thousand)
    
-   **M** for "miljoen" (million)
    

**German:**

-   **Tsd.** for "Tausend" (thousand)
    
-   **Mio.** for "Million" (million)
